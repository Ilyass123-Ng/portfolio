# Ilyas Ennajy — Portfolio

Static single-page portfolio for Ilyas Ennajy, Full-Stack Developer.

## Structure

- `index.html` — main page
- `assets/css/` — styles
- `assets/js/` — scripts and libraries
- `assets/images/` — images and icons
- `_unused_assets_backup/` — template leftovers moved here

## Run locally

Open `index.html` directly in a browser, or serve it with:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

## Notes

External links use `target="_blank"` with `rel="noopener noreferrer"`. Some tech stack icons are loaded from the Devicon CDN.
